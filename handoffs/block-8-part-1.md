## Decisions made (and why)

1. **The reference alignment is the project's first non-circular measure.** The user judged all 73 `vitasilk` rows by hand: **54 correct, 18 wrong, 1 two-tokens, 0 no-token — 74.0% human-confirmed**, 15 of the 18 wrong being cross-script. Committed at `benchmarks/references/align/vitasilk.json`. Hand-made, never regenerated by code, and the only thing that can judge an aligner change without reading the aligner's own output.

2. **The defect is three phantom insertions, not broken cross-script matching.** All 18 wrong rows sit in three runs, each opening with an invented word — `5`, `mn`, `chno` — with the correct Arabic token one row below; each run ends where a Latin token matches exactly. The user confirmed 23 of 39 cross-script pairs as *correct*, so word order was carrying the aligner through. This reframed the whole fix.

3. **Experiment 1 (raise insertion cost) is dead on a structural argument, not a failed search.** All three insertions cost *exactly* what pairing the two words directly costs — 6 vs 6, 10 vs 10, 8 vs 8. The insert wins on backtrace preference alone; flipping only that preference moves every insert at identical total cost, 45 either way. **Both competing paths contain one insertion, so raising its price raises both equally.** No value could ever have worked.

4. **Experiment 2 (transliteration-aware substitution cost) moved 16 of 18 with zero regressions — and is NOT adopted.** Not one of the 54 correct or misheard rows moved. `mn`/`من` costs 0.2 against `mn`/`غير` at 1. Behind a flag; the default model is byte-identical on all five reels. **Adoption requires the user's pass over the 17-row re-review sheet, which a bug prevented.**

5. **Many-to-one is sized and deferred, and its count is a floor rather than a measurement.** 14 bare numerals across five reels, one spanning two draft tokens, and that one is a deletion. The known `26`/`ستة`+`وعشرين` case does not even register as spanning, because the shift absorbed `ستة` — **the aligner's output undercounts merges for exactly the reason the defect exists.** Re-measure after the aligner is fixed.

6. **A fifth verdict, `misheard`**, at reference schema 2: the pairing is in the right place, the machine heard a different word. Counted as a correct alignment, tracked separately because it measures Scribe rather than the aligner. Added after the user was asked to squash two different facts into one button on `msbsb`/`مصبوغ` and `siri`/`ديري`.

7. **A reference judges the aligner, not the repo.** `headSha` moved every session and made the scorer refuse on drift while the aligner was untouched. `alignerHash` now hashes the alignment module and its participating imports; `headSha` stays for provenance. Optional-with-default; a v1 reference falls back rather than being rejected.

8. **The fonts gate moved from Run to Build** (conversation ruling). PROJECT_SPEC §5 reserves K2's fonts for Block 9 and BLOCKS.md orders 8 before 9, so gating the pipeline on fonts made Block 8's DoD unreachable. Fonts affect the comp, not transcription. **Finding underneath it: `requireFonts` was called nowhere outside core — Block 7 built `vitasilk` in Inter Semi-Bold and Almarai Bold purely because the hand-built comps carry them. The fallback was correct and entirely unintended.** Now stated, and Build names both faces.

9. **The panel spawns Node directly, resolved rather than hardcoded.** AE launches from the Finder and inherits no shell profile, so `PATH` holds no nvm. Resolution order: `.local/config.json` → `process.execPath` when it really is node → newest nvm compared numerically → homebrew → `/usr/local`. The resolved path is in the health payload. A version-pinned literal would break on the next Node upgrade and on the partner's machine in Block 10.

10. **One repo-root resolver, and it may never return an empty string.** `getSystemPath('extension')` returns the symlink; `realpathSync('')` returns the cwd, which is the repo under vitest and `/` under a Finder-launched AE — hence `/service/dist/service.js` on screen. It now follows symlinks, walks up, and verifies against `package.json`'s name plus `service/`, `modes/`, `core/`. Failure names all candidates and what each returned.

11. **Responsive two columns above 830 px, on `ResizeObserver`.** The breakpoint is derived, not chosen: a column must never be narrower than the docked single column, where the value side of a fact row is 242 px at the manifest's 420 px; two columns reach 241 px at 820 and 246 px at 830. Session 9's container-query mechanism was invisible to CEP; the rule survived, the mechanism was replaced.

12. **Staged flow, not one page** (user ruling, at handoff). The transcript editor, keyword picker, image picker and zone editor do not fit the current single page. The panel becomes: pick reel → transcript → keywords → images → build, with a way back. **The current screen is step one.**

13. **A dry run before any spend.** Selecting a reel and mode reports each stage as cached or not and what the uncached ones would cost. On `vitasilk`: everything cached, "nothing to pay". This is what makes part 2 affordable and it was built before the thing that spends.
